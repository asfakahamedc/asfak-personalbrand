01 — Brand Strategy Foundation

Who You Are, Precisely

Positioning Statement

"Dhaka-based strategist, operations professional, and geopolitical observer. I write about what power, technology, and market forces mean for people building things in Bangladesh and beyond."

Brand Mission

To make intelligent analysis of complex geopolitical and business systems accessible to professionals building in Bangladesh — cutting through noise with perspective, not prediction.

Brand Promise

Every piece of content delivers a concrete reframe — not a news summary, not an opinion piece dressed as analysis. A specific perspective that changes how a reader sees a system they operate inside.

Brand Personality

Three adjectives. Test each: does your direct competitor claim this word? If yes, it's wrong.

Sharp Grounded Consequential Not: Inspiring Not: Innovative Not: Passionate

The Star of the Show — "The Lens"

Visual Metaphor

The Lens — a precision optical instrument that brings distant, complex things into sharp focus. Every post, article, and piece of content is you applying a trained lens to something most people only see at blur.

This anchors everything visual: precise circular geometry, cross-hair alignment marks, concentric rings, the language of focal depth and clarity. Not decoration — a consistent visual grammar that encodes your core claim: I see this more clearly than most.

Visual Extensions (Shape Rhyming)

  • → Circular elements in logo mark, section dividers, image frames
  • → Fine crosshair / registration marks as decorative accents
  • → Dashed concentric rings as background texture (subtle, 3–5% opacity)
  • → Precision grid lines in illustrations and data graphics

Logo Rules

Maintain minimum clear space equal to the height of the 'A' in "Asfak" on all four sides.
Use only approved color variants: Dark-on-amber, amber-on-dark, dark-on-light, light-on-dark.
Never stretch, skew, rotate, or alter the proportions of the mark or wordmark.
Never place the logo on busy photographic backgrounds without a background treatment (semi-opaque overlay minimum).
Never use drop shadows, gradients, or glow effects on the logo mark.
Minimum digital size: 24px height for icon-only. 120px width for lockup. Below this, use wordmark only.

05 — Motion Language

Motion

Motion is a communication layer, not decoration. Every animation must answer one question: what does the user now understand that they did not before? If there is no answer, the animation is cut.

Duration Ranges

Interaction TypeDurationRule
Micro-interactions (hover, focus)100–200msButton press, link hover, icon state change
UI state changes200–350msDropdown open, modal appear, tab switch
Page route transitions300–400msFade + Y translate between pages
Scroll-triggered reveals400–700msSection elements entering viewport
Stagger delay (per sibling)80ms offsetCard grids, list items appearing

Easing Standards

ContextEasingCSS Value
Elements enteringease-outcubic-bezier(0.0, 0.0, 0.2, 1)
Elements leavingease-incubic-bezier(0.4, 0.0, 1, 1)
Standard interactionsease-in-outcubic-bezier(0.4, 0.0, 0.2, 1)

Never use linear easing for UI motion. Linear feels robotic. Ease functions feel physical.

Animation Patterns

Default Scroll Reveal

Applied to all content sections entering the viewport.

// Framer Motion pattern
const reveal = {
  hidden: { opacity: 0, y: 20 },
  show: {
    opacity: 1, y: 0,
    transition: {
      duration: 0.55,
      ease: [0.0, 0.0, 0.2, 1]
    }
  }
}
// Trigger: useInView at 20% visibility

Stagger Grid

Cards, pillar items, any grid of 3+ elements.

const container = {
  hidden: {},
  show: {
    transition: {
      staggerChildren: 0.08
    }
  }
}
const item = {
  hidden: { opacity: 0, y: 16 },
  show: { opacity: 1, y: 0 }
}

Page Transition

Applied via AnimatePresence in root layout.tsx

initial={{ opacity: 0, y: 8 }}
animate={{ opacity: 1, y: 0 }}
exit={{ opacity: 0, y: -8 }}
transition={{
  duration: 0.3,
  ease: [0.0, 0.0, 0.2, 1]
}}

Hover States

CSS only — Framer Motion is overkill for hover.

/* Card hover */
transition: transform 0.18s ease,
            border-color 0.18s ease;
&:hover {
  transform: translateY(-3px);
  border-color: var(--border-strong);
}

/* Button press */
&:active { transform: scale(0.97); }

Accessibility requirement: All animations must respect prefers-reduced-motion. Wrap in @media (prefers-reduced-motion: reduce) and disable all non-essential motion. Not optional.

06 — Voice & Tone System

Voice & Tone

Voice is permanent — the same in every piece of content. Tone shifts based on the context (informational vs. persuasive vs. supportive). Both are defined below.

Brand Voice Attributes

Direct Consequential Grounded Precise

Test: does every sentence on the site sound like it comes from the same person? If a sentence sounds like it was written by a marketing team, it fails the test.

Voice in Context

❌ Never write like this
  • I'm excited to share my latest analysis on...
  • In today's rapidly evolving landscape...
  • As a passionate advocate for...
  • Join me on this journey of exploration...
  • Thrilled to announce...
  • At the end of the day, it's all about...
  • My thoughts and prayers go out to...
  • Honoured and humbled to...
✓ Write like this
  • China's infrastructure withdrawal matters to Dhaka for three concrete reasons.
  • This happened. Here is what it means. Here is what you should watch next.
  • I got this wrong. Here is what I missed and why it matters.
  • Most analysis stops at the headline. This goes further.
  • The question no one is asking about the BD election...
  • Three decisions I made that killed my UK agency.

Word Avoidance List

These words are either generic, corporate, or signal low-quality thinking. Never use them.

passionate excited to share journey honoured/humbled rapidly evolving world-class cutting-edge synergy leverage ecosystem at the end of the day thought leader holistic game-changer disruptive very really truly

Tone by Context

Informational

Used in: analyses, Substack issues, website copy about your work.

Precise, direct, no jargon. State the fact. State the implication. Move on.

Persuasive

Used in: CTAs, outreach messages, LinkedIn posts, agency pages.

Confident, benefit-led. What they gain. Not what you offer.

Personal / Transparent

Used in: Founder/Life pillar, About page, failure posts.

Raw without being self-pitying. Honest without being confessional. Keep it consequential.

08 — Photography & Imagery

Visual Direction

Photography Style
Natural light. Environmental over studio. You in context — at a desk, in Dhaka, working — not posed against a neutral backdrop.
Color Treatment
Desaturate by 15–25%. Lift shadows slightly. Add warm tint (+5 temperature). Never oversaturate. Never Instagram filter.
Subject Matter
Maps, data visualizations, architectural detail, newsprint textures, street-level Dhaka photography (selective, not tourist-facing).
Graphic Style
Sparse line illustrations. Precision diagrams. Minimal decorative elements. All illustrations must use the brand color system.
What to Avoid
Stock photos. Handshakes. Laptops at coffee shops. Globe graphics. Any image that looks like it came from Unsplash's "business" category.
Icon System
Lucide React icon library. Stroke weight: 1.5px. Size: 16px or 20px only. Never filled icons — outline only. Amber color only or text-secondary.

CRO Principles Applied

Hero section communicates: What it is, Who it's for, Why it matters, and What to do next — in under 5 seconds, no scrolling required.
CTA appears in navigation (persistent), hero, and repeated every 600–900px of content. CTA copy: verb + outcome. "Read the Analysis" not "Click Here."
Specificity rule: "47 clients" not "many clients." "3 years in operations" not "years of experience." Replace every vague claim with a specific one.
No outbound links in post body — they go in the first comment (LinkedIn rule applied to website: no navigation away from conversion path).
Contact form: name + email only. Every additional field is friction that costs you conversions you will never recover.

Why Keystatic Over FireCMS

Keystatic (Recommended)

  • → 100% free, open source, no vendor lock-in
  • → Content stored as MDX files in GitHub repo — you own it
  • → Works natively with Next.js App Router
  • → No separate database needed for blog content
  • → Admin UI built in — edit posts at /keystatic
  • → Deploys with the same Vercel pipeline

FireCMS (Alternative)

  • → Free self-hosted, requires Firebase project
  • → Content stored in Firestore (more complex setup)
  • → Better fit if you need a full database CMS
  • → Requires more Firebase configuration
  • → Use this if/when the agency site needs a full product catalog or client portal
